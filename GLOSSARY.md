# Glossary

Current open lesson ke terms aur concepts. Jaise-jaise agle lessons naye words introduce karenge, woh yahan add hote jayenge.

---

## Variable

Ek descriptive naam jo memory mein kisi value ko hold karke rakhta hai.
* *Example:* `machine_name = "Pump-A"` ya `temperature_celsius = 72.5`.
* *Production intuition:* Reading ko naam dene se plant alarms aur displays ek hi source of truth ko refer karte hain.

---

## Value

Woh underlying data jo variable hold karta hai (jaise text string `"Pump-A"`, integer `10`, ya float `72.5`).

---

## Assignment

`=` operator wala execution step. Right-hand side ki expression evaluate hoti hai aur uska result left-hand side ke variable name se bind ho jata hai.
* *Example:* `latest_reading = "80.1"` purani value ko overwrite karke naya state register karta hai.

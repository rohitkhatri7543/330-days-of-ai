1. Pump-A ka temperature log, display, aur alarm teeno use karte hain. Tumne teeno jagah `72.5` type kar diya. Sensor `80.1` bhejta hai aur tum sirf log update karte ho. Alarm kya number dekhega, aur line pe iska kya real-world consequence hoga?

3. `unit = "C"` ek baar likha gaya, aur `label` usi variable ko padhta hai. Kal plant unit `F` (Fahrenheit) kar de, to ek assignment se pura output kaise update hota hai, aur hardcoded `"C"` likhne se kya risk hota hai?

4. `machine_status("running", "M-12")` call mein parameters ka order ulta ho gaya. Agar code argument names ke order ko theek se na pakde, to dashboard pe status aur machine id kaise swap ho sakte hain?
